# roux-archinstall

This is a script to automate the process of setting up NixOS. It is
primarily intended to be run on a fresh installation of NixOS.

# Usage

> ⚠️ **WARNING**: Make sure to create proper backups of any important data on
> your machine before running this script!!!\
> Additionally, I highly recommend you read through the script and
> modify/disable sections of the installation that you're not interested in.

As a regular user run the following commands from any directory under your user
folder.

```
git clone --depth 1 https://github.com/imroux/roux-nixinstall.git
cd roux-nixinstall
./setup-nixos.sh
```
